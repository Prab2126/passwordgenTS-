# Password Generator

This is my second project made in TS which help to make my logic more clear in TS.
In this project password got animated when every changed with any button.

## Use project locally

If having git then ok if not then first install git on your system.

```bash
git clone https://github.com/Prab2126/passwordgenTS-.git
```

Migrate it on this folder `passwordgenTS`

```bash
cd passwordgenTS
```

use nodejs npm manager to install the nodeModule folder on the current project to run the vite

```bash
npm i
```

or

```bash
npm install
```

now run the project by the vite binary

```bash
npm run dev
```

or

```bash
npx vite
```
